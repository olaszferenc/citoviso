# Portál-iCal minták: források

Gyűjtve: 2026-10-12. Minden fájl a forrásban szó szerint szereplő szöveg. A tartalmat nem javítottam: a sorvég (CRLF/LF), a tördelés és a mezősorrend a forrásé.

Kétféle eltérés van a nyers forráshoz képest, mindkettő a táblázatban jelölve:
- **(a) Anonimizálás.** A vendégnév a SUMMARY-ban „Vendég A…”-ra cserélve. A foglalási kód és az URL-ben lévő foglalási kód ugyanolyan hosszú `X`-sorozat lett. A telefonszám MINDEN számjegye `X`, az elválasztók maradnak (a fába kerülés előtt a teljes számot maszkoltuk, nem csak az utolsó 4 jegyet). A vendég alias e-mail-címének helyi része ugyanolyan hosszú `x`. Ahol lehetett, azonos hosszra maszkoltam, így a tördelés szélessége is megmaradt.
- **(b) A közlés burkolata levéve.** Ilyen a markdown `> ` idézőjel, a kódblokk egységes behúzása és a Kotlin `trimIndent()`. Ezek a poszt megjelenítéséhez tartoznak, nem a feedhez.

Ahol a posztoló már maga anonimizált (`bla`, `XXXX`, `1111`, `<CustomerName>`), azt változatlanul hagytam.

## Ahol kerestem, de nem találtam

- **Szállás.hu:** WebSearch magyarul és angolul, GitHub issue-keresés („szallas ical”, „szallas.hu ical”). Nincs nyilvános feedminta, és a súgóoldal sem mutat formátumot.
- **Expedia, Hostelworld, Smoobu, Beds24, Lodgify:** GitHub issue-keresésben és a Discourse-fórumokban (Home Assistant, Hubitat, openHAB, Jeedom) nincs bemásolt feed. A Beds24-wiki és a Lodgify-blog csak leírja az exportot. Az iPRO súgó állítólag közöl VRBO-mintát (`-//VRBO//Booking Calendar 1.0//EN`), de csak belépéssel olvasható, ezért kihagytam.
- **Nem portál, ezért kihagyva:** Host Tools PMS-export (HA-fórum, 383246/#122), Guesty-részlet (#245), a rental-control saját formátuma (tykeal #176).
- **Elérhetetlen volt:** a MotoPress-fórum (Cloudflare 403), a régi community.withairbnb.com (átirányít) és az archive.org (offline volt).
- **Szándékosan nem nyitottam meg:** egy nyilvános oldalon kiszivárgott, tokenes `admin.booking.com/hotel/hoteladmin/ical.html?t=…` linket. Ez valakinek a privát feedje.
- **Keresőeszközök:** GitHub issue-keresés API (nem hitelesített), Sourcegraph nyilvános kódkeresés (a portál-PRODID-kre a 2 fixtúrán kívül nincs találat), StackExchange API, Discourse `search.json`. A GitHub kódkereséshez és a grep.app-hoz hitelesítés kell, illetve blokkolva voltak.

## Hogyan használja az őr

`scripts/portal-ical-samples-check.mts` minden mintát a valódi parserrel (`importIcsBlockedDays`, Europe/Budapest) olvas,
és a `manifest.json`-ban rögzített foglalt éjszakákat várja. Az elvárások FÜGGETLENÜL igazoltak: a python `icalendar` 7.3
könyvtárral (DTSTART..DTEND kizáró, a részleteket VCALENDAR-keretbe téve) mind a 20 nem üres mintán ugyanaz a
nap-halmaz jött ki (2026-10-12). A „részlet” minták (fejléc nélkül) `ownerWarnings`-szal szerepelnek: valódi
letöltésnél a fejléc nélküli válasz már a `fetchFeed`-en elbukik („nem naptár”).
